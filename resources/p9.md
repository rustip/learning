## Unit 5: Putting It All Together

With help from your mentor, pick one or two projects and implement them in a week or two using the knowledge you have gained over the past few months.

- Create guidelines for secrets management, security, CI, and coding. Enforce them through linting tools and CI workflows where possible.
- Implement the projects with a few microservices using REST (Axum) or gRPC (Tonic), a PostgreSQL database (SQLx), and Docker, Podman, or Pod containers. Optionally, use Kubernetes (EKS or similar).
- Write integration tests and unit tests with good coverage. Design a CI pipeline and define it using GitHub Actions. Deploy the projects to your preferred cloud platform through CI workflows.
