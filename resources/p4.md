# Resources: Part 4

## Unit 1: Algorithm Analysis

Understand the time and space complexity of important algorithms and data structures using [Analysis of Algorithms by Steven Skiena](https://www.youtube.com/playlist?list=PLOtl7M3yp-DXbHTFe_w9zFPXeau28CDao). Videos 1 to 6 and 8 should be enough.
You could also refer to his book [The Algorithm Design Manual](https://www.amazon.com/Algorithm-Design-Manual-Computer-Science/dp/3030542556).

## Unit 2: Generic Programming in Rust

Read chapters 10 through 12 of the book `The Rust Programming Language`. Spend extra time on Chapter 10.

**Lab for Units 1 and 2**:

Implement all the algorithms and data structures you learned previously using Rust and generics. You can use basic collections from the Rust standard library for some of these (e.g., Vec). Keep the implementations generic where possible.

For example:

- Binary Search
- Quicksort and merge sort
- Hash table
- Binary search tree: insertion and traversal

## Unit 3: Continuous Integration and Continuous Deployment

Start with a simple introduction to continuous integration and continuous deployment:

- [Continuous Integration](https://www.youtube.com/watch?v=1er2cjUq1UI)
- [Continuous Testing](https://www.youtube.com/watch?v=RYQbmjLgubM)
- [Continuous Delivery](https://www.youtube.com/watch?v=2TTU5BB-k9U)
- [Continuous Deployment vs. Continuous Delivery](https://www.youtube.com/watch?v=LNLKZ4Rvk8w)

Read chapters 3 through 5 of [Continuous Delivery](https://www.amazon.com/Continuous-Delivery-Deployment-Automation-Addison-Wesley-ebook/dp/B003YMNVC0).

Read the blog article [Branching Patterns](https://martinfowler.com/articles/branching-patterns.html) or watch [Branching Strategies Explained](https://www.youtube.com/watch?v=U_IFGpJDbeU).

Watch the “Git Tools and Techniques” section of the Master.dev Git course.

**Lab**: Learn [Git workflows](https://www.youtube.com/watch?v=GQQqf-C2ha4). With your mentor, decide on a [commit message format](https://tbaggery.com/2008/04/19/a-note-about-git-commit-messages.html) and branching strategies. Implement an AI agent skill for these conventions and use it for all of your code.
