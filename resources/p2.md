# Resources: Part II

## Unit 1: Information Model

Most modern solutions to distributed systems problems are based on the following fundamental idea. Understanding it is critical for learning later concepts, so watch the video twice (on Monday and then on Friday).

- [Database as a Value](https://www.youtube.com/watch?v=EKdV1IgAaFc)

Optionally, watch the following video first.

- [Simple Made Easy](https://www.youtube.com/watch?v=SxdOUGdseq4)

Understand the ideas above by learning the internals of Git. Git is a distributed system and broadly follows these principles.

- [Git Internals - A Database Perspective](https://www.youtube.com/watch?v=6b6iOPvspPs)
- [Git Internals](https://www.youtube.com/watch?v=lG90LZotrpo)
- [The Git Parable](https://www.infoq.com/presentations/git-details/)

Once you have a good understanding of Git internals and how they relate to value, identity, and time, read the following paper. You don't need to finish it.

- [Why Functional Programming Matters](https://www.cse.chalmers.se/~rjmh/Papers/whyfp.pdf)


## Unit 2: Rust

Rust is a safe systems programming language. Rust is not a functional programming language. Rust will teach you the fundamentals of writing good code without requiring you to adopt a fully functional programming paradigm, making it far more useful for everyday Java, TypeScript, and Python programming.

Try to understand why Rust works and why software written in Rust is predictable compared with software written in other imperative languages. Also, understand how it is largely equivalent to functional programming languages like Scala, Clojure, or Elixir.

Read the first six chapters of [The Rust Programming Language](https://rust-book.cs.brown.edu/). This version is interactive and lets you execute most of the code inline.
If you prefer videos, watch the [Ultimate Rust Lang tutorial](https://www.youtube.com/watch?v=OX9HJsJUDxA&list=PLai5B987bZ9CoVR-QEIN9foz4QCJ0H2Y8). This covers almost all of the book.

If you find the Rust book too complex, use the following sections from [The Rust Programming Language](https://master.dev/courses/rust/).

- Introduction
- Collections
- Pattern matching
- Vectors

**Lab**: Pick 10-20 small programs from [Exercism](https://exercism.org/tracks/rust/exercises) and implement them in Rust. Some of them might require more advanced Rust features; skip those.


## Unit 3: Git

Learn advanced concepts in Git using [Everything You'll Need to Know About Git](https://master.dev/courses/everything-git/).

Watch the following sections:

- Branching, Merging, and Rebasing
- Working with Remote Repositories
- Conflict Resolution

Optionally, watch Git Basics.

For those who prefer a book, use [Learning Git](https://www.amazon.com/Learning-Git-Hands-Visual-Basics/dp/1098133919). This is a detailed hands-on approach to Git. This is a short book. Cover chapters 3 to 5 and 9 to 12.

Use both resources if possible. When the videos are difficult, read about the same topic in the book. If a concept is absent from the book, watch the video.

**Lab**: Use [GitHub Skills](https://learn.github.com/skills). Complete the “First week on GitHub” section.
