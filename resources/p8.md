# Part 8: Distributed Applications

## Unit 1: Kubernetes Basics

Learn the basics by covering “Getting Started with Kubernetes” from [Kubernetes: Production-Grade Container Orchestration](https://master.dev/courses/kubernetes/) and/or [Kubernetes and EKS for Beginners – Crash Course with Pulumi](https://www.youtube.com/watch?v=hK8wf18SasY&t=2463s).

You could also follow the interactive tutorial on the [official Kubernetes website](https://kubernetes.io/docs/tutorials/kubernetes-basics/).

Learn the concepts from [Kubernetes on Azure](https://www.youtube.com/watch?v=EUitQ8DaZW8&list=PLLasX02E8BPBgWVG_bS-b6EvUZDo-KIFO).

Kubernetes is a complex topic. Do not attempt to learn everything. Developers need to have a good conceptual understanding and only need to know the basics. You can learn the rest on the job. For DevOps roles, the material above won't be enough.


## Unit 2: Security

### Secure APIs

- Read the first three chapters of [Secure APIs](https://www.amazon.com/Secure-APIs-Design-build-implement/dp/1633436632).
- [SEVEN things about API security](https://www.youtube.com/watch?v=QBMgAOKrdes)
- Use [API Security Top 10](https://owasp.org/projects/api-security-project). Watch [Securing Your API: The OWASP Top 10 - Rob Allen](https://www.youtube.com/watch?v=OKSP-akKuYs).

### Authentication and Authorization

You already know the basics of authentication. Learn authentication and authorization concepts along with RBAC from [Authorization in Action](https://www.amazon.com/Authorization-Action-Phil-Windley/dp/1633435172).

Use [RBAC in Rust with Axum](https://casbin.incubator.apache.org/docs/rust-rbac-tutorial/) to implement authorization in the Part 6 lab. You could also use Auth0 instead for [authentication](https://auth0.com/blog/type-safe-authentication-rust-auth0-axum/) and [device-flow authentication and JWT validation](https://auth0.com/blog/device-authorization-flow-rust-cli-axum-api/).

### Secrets Management

This is a topic that depends heavily on the tech stack or platform you are using. Here are some examples. Your mentor will help you find suitable resources.

- Learn the basics of secret management with [Introduction to Vault](https://www.youtube.com/watch?v=eA_9WwYwXp0).
- For small or simple local development projects, use [SOPS with age](https://www.youtube.com/watch?v=1BquzE3Yb4I). It works well with [Nix](https://www.youtube.com/watch?v=G5f6GC7SnhU) too.
- For simple web development, use [Varlock](https://www.youtube.com/watch?v=nxH-BrsCPTo&t=35s).
- [HashiCorp Vault](https://developer.hashicorp.com/vault/tutorials/get-started-for-developers) is an excellent secrets manager.
- [Doppler](https://www.youtube.com/watch?v=-RamASjC-Ng&list=PLIsrO5q74h2f8K2mhu2IvIg8qO7Begs0g) is another secrets manager that works with most cloud platforms.
- Do not use .env files.

## Unit 3: Distributed Services

A microservices architecture is one way to implement distributed applications. Even if you don't use microservices, learning about them is still useful, as most of the literature on applied distributed systems focuses on the microservices ecosystem.

Start with the following videos:

- [Principles Of Microservices by Sam Newman](https://www.youtube.com/watch?v=PFQnNFe27kU)
- [DDD & Microservices: At Last, Some Boundaries!](https://www.youtube.com/watch?v=yPvef9R3k-M)
- [Microservices in Rust](https://www.youtube.com/watch?v=JkSa-qA2jnY)

Microservices in production:

Read chapters 1 through 3 and 9 through 12 of [Microservices Patterns](https://www.amazon.com/Microservices-Patterns-examples-Chris-Richardson/dp/1617294543), and implement the patterns in Rust where possible.

- [Security And Microservices - Sam Newman](https://www.youtube.com/watch?v=qw_Z5TyQIb8&t=1776s&pp=ygUYc2FtIG5ld21hbiBtaWNyb3NlcnZpY2Vz)
- [Deploying And Scaling Microservices - Sam Newman](https://www.youtube.com/watch?v=sO0RKuVhfw4)
- [Sam Newman: "Deploying And Testing Microservices"](https://www.youtube.com/watch?v=FotoHYyY8Bo)

Read chapters 7 through 13 of [Building Microservices](https://www.amazon.com/Building-Microservices-Designing-Fine-Grained-Systems/dp/1492034029).


## Unit 4: Observability

You have already covered the basics of observability.

- Read Part II (chapters 5 through 9) of [Observability Engineering](https://www.amazon.com/Observability-Engineering-Achieving-Production-Excellence/dp/1492076449).
- [Observability Full Course: Logs, Metrics & Traces](https://www.youtube.com/watch?v=jhS_VD247Qo&t=22784s) is a comprehensive practical course, but it uses Go. If you have time, work through it.
- Read the first four chapters of [Learning OpenTelemetry](https://www.amazon.com/Learning-OpenTelemetry-Setting-Operating-Observability/dp/1098147189).
- Implement observability in your projects using [OpenTelemetry (and tracing)](https://opentelemetry.io/docs/languages/rust/getting-started).
