# Part 8: Distributed Applications

## Unit 1: Distributed services

A microservices architecture is one way to implement distributed applications. Even if you don't use microservices, learning about them is still useful, as most of the literature on applied distributed systems focuses on the microservices ecosystem.

Start with the following videos:

- [Principles Of Microservices by Sam Newman](https://www.youtube.com/watch?v=PFQnNFe27kU)
- [DDD & Microservices: At Last, Some Boundaries!](https://www.youtube.com/watch?v=yPvef9R3k-M)

Then read the relevant chapters of [Building Microservices](https://www.amazon.com/Building-Microservices-Designing-Fine-Grained-Systems/dp/1492034029).

Learn the necessary patterns from [Microservices Patterns](https://www.amazon.com/Microservices-Patterns-examples-Chris-Richardson/dp/1617294543).

## Unit 2: Event-driven systems

Event-driven architecture is a pattern used in large enterprise systems. Watch the following videos to get a good foundation. There is a lot of overlap, so feel free to skim the duplicate parts.

- [Transactions: myths, surprises and opportunities](https://www.youtube.com/watch?v=5ZjhNTM8XU8)
- [Thinking in events](https://www.youtube.com/watch?v=72W_VvFRqc0)
- [Turning the database inside out with Apache Samza](https://www.youtube.com/watch?v=fU9hR3kiOK0)
- [Building real-time data products at LinkedIn with Apache Samza](https://www.youtube.com/watch?v=yO3SBU6vVKA)
- [ETL Is Dead, Long Live Streams: real-time streams w/ Apache Kafka](https://www.youtube.com/watch?v=I32hmY4diFY)

Watch the following talk to understand why you might use Temporal:

- [Glovo Tech Talks - Fault tolerant distributed microservices with Temporal](https://www.youtube.com/watch?v=6lSuDRRFgyY&list=LL&index=8)
