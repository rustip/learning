# Part 8: Distributed Applications

## Unit 1: Kubernetes Basics

- Learn the concepts from [Kubernetes on Azure](https://www.youtube.com/watch?v=EUitQ8DaZW8&list=PLLasX02E8BPBgWVG_bS-b6EvUZDo-KIFO).

- Learn the basics with “Getting Started with Kubernetes” from [Kubernetes: Production-Grade Container Orchestration](https://master.dev/courses/kubernetes/), [Kubernetes and EKS for Beginners – Crash Course with Pulumi](https://www.youtube.com/watch?v=hK8wf18SasY), or [Introduction to Kubernetes for Developers](https://www.youtube.com/watch?v=iIPPjzkPrss).

- You could also follow the interactive tutorial on the [official Kubernetes website](https://kubernetes.io/docs/tutorials/kubernetes-basics/).

Kubernetes is a complex topic. Do not attempt to learn everything. Developers need to have a good conceptual understanding and need to know the basics. You can learn the rest on the job. For DevOps roles, the resources above won't be enough.


## Unit 2: Security

### Secure APIs

The following talks briefly cover most topics:

- [API Security By Design - Jose Haro Peralta](https://www.youtube.com/watch?v=1umk2vd7jVw)
- [API Security By Design](https://www.youtube.com/watch?v=acXpD1tRmCQ)
- [SEVEN things about API security](https://www.youtube.com/watch?v=QBMgAOKrdes)
- [The One Where We Threat Model During Development - Izar Tarandach](https://www.youtube.com/watch?v=_Pam1hkkzyM)

The following book covers the topics in more depth:

- Read chapters 1, 2, 3, and 12 of [Secure APIs: Design, build, and implement](https://www.amazon.com/Secure-APIs-Design-build-implement/dp/1633436632).

The following resources cover the OWASP API Security Top 10 list:

- [API Security Top 10](https://owasp.org/projects/api-security-project)
- [Securing Your API: The OWASP Top 10 - Rob Allen](https://www.youtube.com/watch?v=OKSP-akKuYs)

You could also consider the following interactive course from the Linux Foundation:

- [Developing Secure Software](https://training.linuxfoundation.org/training/developing-secure-software-lfd121)

### Authentication and Authorization

You already know the basics of authentication.

- Read chapter 7 of [Secure APIs](https://www.amazon.com/Secure-APIs-Design-build-implement/dp/1633436632).
- Learn authentication and authorization concepts along with RBAC from [Authorization in Action](https://www.amazon.com/Authorization-Action-Phil-Windley/dp/1633435172).

### Lab

- Use [RBAC in Rust with Axum](https://casbin.incubator.apache.org/docs/rust-rbac-tutorial/) to implement authorization in the Part 6 lab.
- You could also use Auth0 instead for [authentication](https://auth0.com/blog/type-safe-authentication-rust-auth0-axum/).
- Learn about [device-flow authentication and JWT validation](https://auth0.com/blog/device-authorization-flow-rust-cli-axum-api/).

### Secrets Management

This is a topic that depends heavily on the tech stack or platform you are using. Here are some examples. Your mentor will help you find suitable resources.

- Learn the basics of secret management with [Introduction to Vault](https://www.youtube.com/watch?v=eA_9WwYwXp0).
- For small or simple local development projects, use [SOPS with age](https://www.youtube.com/watch?v=1BquzE3Yb4I). It works well with [Nix](https://www.youtube.com/watch?v=G5f6GC7SnhU) too.
- For simple web development, use [Varlock](https://www.youtube.com/watch?v=nxH-BrsCPTo).
- [HashiCorp Vault](https://developer.hashicorp.com/vault/tutorials/get-started-for-developers) is an excellent secrets manager.
- [Doppler](https://www.youtube.com/watch?v=-RamASjC-Ng&list=PLIsrO5q74h2f8K2mhu2IvIg8qO7Begs0g) is another secrets manager that works with most cloud platforms.
- [Microsoft Security Adoption Framework](https://learn.microsoft.com/en-us/security/zero-trust/security-adoption-model)
- [Microsoft secrets best practices](https://learn.microsoft.com/en-us/azure/security/fundamentals/secrets-best-practices)

## Unit 3: Distributed Services

A microservices architecture is one way to implement distributed applications. As most of the literature on applied distributed systems comes from the microservices ecosystem, learning about microservices is essential.

Start with the following videos:

- [Principles Of Microservices by Sam Newman](https://www.youtube.com/watch?v=PFQnNFe27kU)
- [DDD & Microservices: At Last, Some Boundaries!](https://www.youtube.com/watch?v=yPvef9R3k-M)
- [Microservices in Rust](https://www.youtube.com/watch?v=JkSa-qA2jnY)

Microservices in production:

- [Security And Microservices - Sam Newman](https://www.youtube.com/watch?v=qw_Z5TyQIb8)
- [Deploying And Scaling Microservices - Sam Newman](https://www.youtube.com/watch?v=sO0RKuVhfw4)
- [Sam Newman: "Deploying And Testing Microservices"](https://www.youtube.com/watch?v=FotoHYyY8Bo)
- Read chapters 7 through 13 of [Building Microservices](https://www.amazon.com/Building-Microservices-Designing-Fine-Grained-Systems/dp/1492034029).

Decomposing a monolith:

- [Monolith Decomposition Patterns - Sam Newman](https://www.youtube.com/watch?v=9I9GdSQ1bbM)
- Read chapter 13 of [Microservices Patterns](https://www.amazon.com/Microservices-Patterns-examples-Chris-Richardson/dp/1617294543).

### Lab

Read chapters 1 through 3 and 9 through 12 of [Microservices Patterns](https://www.amazon.com/Microservices-Patterns-examples-Chris-Richardson/dp/1617294543), and implement the patterns in Rust where possible. The book includes Java code.
